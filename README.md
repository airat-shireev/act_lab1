Simulink модель двигателя постоянного тока с последовательным возбуждением

Двигатель обладает следующими характериситиками: 
Jдв =7∙10−6 (кг∙м2) 
𝐶𝑀=1.3 ( (Н∙м)/(Гн∙А2) )
𝐶ω=3.15( (В∙с)/(Гн∙А) ) 
𝐿я=0.0015 (Гн)  
𝑅я=8 (Ом) 
𝐿ов =0.013 (Гн)

Модель позволяет построить графики зависимости тока, момента и скорости от времени, а также механическую характеристику двигателя

Чтобы воспользоваться моделью необходимо сначала задать входное напряжение, а затем запустить модель и проанализировать графики
